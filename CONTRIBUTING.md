# Contributing to Haleva

Thanks for your interest in improving Haleva! This document explains how to contribute.

## Ways to contribute

- Report bugs via GitHub Issues
- Suggest features
- Improve documentation
- Submit pull requests
- Share Haleva with others

## Development setup

1. Fork the repository
2. Clone your fork: git clone https://github.com/YOUR_USERNAME/haleva.git
3. Create a branch: git checkout -b feature/your-feature
4. Install Docker Desktop
5. Copy .env.example to .env and fill in your keys
6. Run: docker compose up -d

## Pull request process

1. Update README.md if needed
2. Follow the existing code style
3. Test your changes locally
4. Write clear commit messages
5. Open a PR with a clear description

## Commit message convention

- feat: new feature
- fix: bug fix
- docs: documentation
- chore: maintenance
- refactor: code restructure

## Code of conduct

By participating, you agree to our Code of Conduct.

## Questions?

Open a GitHub Discussion or Issue.
